# Codex 原生导航与中文补全

开启 Codex 内置侧边栏导航功能，以及启用和补全中文界面。

脚本开启原生导航功能开关和官方国际化支持，保留 Codex 自身的语言选择。中文补全仅在应用实际使用简体中文时生效；选择 English 或其他语言后恢复脚本替换过的原文。自动检测解析为简体中文时也会补全，不向繁体中文界面注入简体译文。

补全范围包括设置导航、登录启动、存储管理、浏览器站点工具、快捷键和部分虚拟宠物描述。优先使用官方翻译，不翻译聊天内容、代码或输入框，不修改配置文件。

DOM 变化按帧合并，只处理相关增量；定时检查仅用于发现迟到的功能开关客户端，不定时扫描设置全文。停用时撤销仍由本脚本持有的文本及接口修改。

## 安装与兼容

从 Codex++ 拓展市场安装后启用。已有手动安装的旧版 `codex-native-navigation.js` 时，请先停用旧版，避免两份脚本同时运行。

依赖 Codex 内部 Statsig 开关、语言标记和设置页结构。已针对桌面版 `26.1007.9446.0` 检查，后续应用更新可能需要调整。

## 验证

使用现有 Playwright 环境运行：

```text
node tests/codex-native-navigation.browser.cjs
```

覆盖语言切换、补全文本恢复、动态文案、输入及代码保护、功能开关转发、无关聊天更新的扫描开销，以及停用清理。
